# Business International – Steel Supplier Website

Single-page website (HTML/CSS/JS, no build step).

## Files
- `index.html` – the whole site
- `images/` – owner photo and product photos

## Edit in VS Code
Search `const CONFIG=` in index.html: business name, WhatsApp number (digits only, country code first), phone, email.
Search `const P=[`: products. To use a real photo add a 7th item to a row, e.g. `"images/hrc.jpg"`. Rows without it keep the drawn illustration.
Placeholders to replace: street address, email, Google Map, social links, privacy policy, testimonials, payment text in FAQ.

## Publish on GitHub Pages
1. Create a repo, upload these files (index.html at the root).
2. Settings > Pages > Deploy from branch > main / root.
3. Site goes live at https://USERNAME.github.io/REPO/
